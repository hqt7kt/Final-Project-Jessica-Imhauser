# FINAL PROJECT: LIGO Gravitational Wave Analysis

### This project uses a dataset from LIGO (the Laser Interferometer Gravitational-Wave Observatory) gravitational-wave detections, containing properties of binary black hole mergers such as chirpmass, redshift, and signal-to-noise ratio. Each row in the dataset represents a gravitational wave event and includes measurements of both the physical system and the detection strength. The main question I sought to answer when analyzing this data set was how the masses of merging black hole pairs affect the strength of gravitational wave signals detected by LIGO. The main finding was that higher mass black hole mergers tend to produce stronger gravitational-wave signals on average. This was shown throughout the data analysis by a longer tail on the high end of the High Mass SNR Distribution histogram and a few percent increase in detectability for high mass events. Additionally, a statistical test was conducted to check whether the signal strength between high and low mass black hol mergers was statistically significant or due to random chance. The test computed a p-value of about 0.1770, which is not statistically significant. However, the other observed trends still suggest a possible relationship between mass and signal strength.
